Provenance
----------
The final processed dataset was prepared from two Kaggle source inputs provided by the authors:

1. Solar power generation input:
   https://www.kaggle.com/code/pythonafroz/solar-power-generation-forecast/input

2. Solar prediction / weather input:
   https://www.kaggle.com/code/volkanarslan97/solar-prediction/input

The final file, Solar_Weather_Data_Processed.csv, is a curated and processed derivative dataset prepared for machine learning experiments. It contains hourly weather/solar features and PV AC output values for supervised solar power forecasting.

Important academic wording
--------------------------
The dataset should not be described as a fully original raw field-measured dataset created entirely by the authors. It should be described as a curated and processed dataset derived from publicly available Kaggle source data.

Recommended wording:
"The dataset used in this study was prepared by integrating publicly available PV generation and solar-weather datasets obtained from Kaggle. The final processed dataset and preprocessing code were deposited in Mendeley Data to support reproducibility."

License guidance before publication
-----------------------------------
Before selecting the Mendeley license, verify the license shown on each original Kaggle source page or source dataset page. The Mendeley license should be compatible with the original source licenses.

Use this rule:
- If both original Kaggle datasets are CC0, a CC0 or CC BY 4.0 Mendeley license is usually acceptable.
- If either original dataset is CC BY, retain attribution and use CC BY 4.0 or another compatible attribution license.
- If either original dataset is CC BY-NC, do not publish the derivative under a commercial-use license.
- If either original dataset has No Derivatives (ND) restrictions, do not publish a modified merged dataset without permission.
- If the license is unknown or missing, do not claim unrestricted reuse. Publish the preprocessing code and final research data only after confirming permission.
